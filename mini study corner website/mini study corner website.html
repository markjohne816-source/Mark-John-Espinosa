Z-Index Challenge

z-index: 1
z-index: 5
z-index: 10
Why is the top box displayed above the others?
The box with z-index: 10 sits on top because a higher z-index value places an element closer to the viewer along the stacking (z) axis. All three boxes overlap in the same 2D space, so the browser uses z-index to decide the paint order — highest value wins.

Reflection

  1. Which CSS property was the easiest to use? The easiest property was color or background-color, because it’s straightforward: you assign a value and instantly see the change.
  2. Which property was the most challenging? The most challenging property was likely z-index, as it requires understanding of the stacking context and how elements are layered.
  3. Where can sticky positioning be useful in real websites? Sticky positioning is useful for creating navigation bars that remain visible while scrolling, or for creating sections that stay in view as the user scrolls down the page.
  4. What happens if z-index is removed? If z-index is removed, elements will be stacked in the order they appear in the HTML, with later elements appearing on top of earlier ones.
  5. Why is relative positioning important when using absolute positioning? Relative positioning establishes a containing block for absolutely positioned child elements, allowing them to be positioned relative to their normal position within the document flow.
